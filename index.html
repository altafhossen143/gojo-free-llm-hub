⚔️ ব্যাটল মোড — কোন মডেল ভালো?

একই প্রম্পট দুটো মডেলকে পাঠান। উত্তর আসবে নাম গোপন রেখে — Model A আর Model B হিসেবে। যেটা ভালো লাগবে ভোট দিন, তারপরই জানা যাবে কোনটা কোন মডেল।

মডেল তালিকা আসে এখনকার প্রোভাইডারের লোড করা তালিকা থেকে। তালিকা খালি থাকলে উপরে “মডেল লোড করুন” চাপুন। দুটো মডেল একই প্রোভাইডার ও একই key দিয়ে চলবে।

📖 সেটআপ গাইড — কোনটা কিভাবে কাজ করে

১) OpenRouter — সবচেয়ে সহজ (২ মিনিট)

  1. openrouter.ai-তে ফ্রি অ্যাকাউন্ট খুলুন, Keys পেজ থেকে API key বানান।
  2. Key-টা উপরের Settings-এ পেস্ট করে সেভ করুন।
  3. দামের ফিল্টারে “শুধু ফ্রি” রেখে মডেল লোড করুন — FREE মানে :free বা $0 মডেল; পেইড মডেলে ক্রেডিট কাটবে।
  4. মডেল বেছে চ্যাট শুরু করুন।

২) Groq / Cerebras / Mistral — ফ্রি টিয়ার key দিয়ে

  1. প্রতিটার ফ্রি অ্যাকাউন্ট খুলে key বানান (লিংক Settings ও ডিরেক্টরিতে আছে)।
  2. Settings-এ সংশ্লিষ্ট ঘরে key বসিয়ে সেভ করুন, উপরে ওই প্রোভাইডার বাছুন।
  3. “মডেল লোড করুন” চাপুন — তালিকা আসবে ওই প্রোভাইডারের /models endpoint থেকে, লাইভ।

৩) Custom Endpoint — যেকোনো নতুন প্রোভাইডার নিজে যোগ করুন

Gemini, Together, Hugging Face, GitHub Models, OpenAI, Ollama — Settings-এর Custom ঘরে Base URL আর key বসান, “Custom Endpoint” প্রোভাইডার বাছুন, মডেল লোড করুন। তালিকা না এলে Custom মডেল ID হাতে লিখে দিন।

৪) FreeLLMAPI — নিজের সার্ভারে চলে

FreeLLMAPI ওপেন-সোর্স প্রক্সি — নিজের কম্পিউটার/সার্ভারে চালাতে হয়। ভেতরে ফ্রি key গুলো জোড়া লাগিয়ে একটাই unified key দিয়ে সব মডেল চলে।

  1. GitHub repo থেকে clone করে README অনুযায়ী install + চালু করুন।
  2. ড্যাশবোর্ডে নিজের ফ্রি প্রোভাইডার key গুলো যোগ করুন।
  3. সার্ভার ডিফল্টে localhost:3001-এ চলবে। ড্যাশবোর্ড থেকে unified key কপি করুন।
  4. Settings-এ Base URL ও unified key বসিয়ে সেভ করুন, FreeLLMAPI প্রোভাইডার বেছে মডেল লোড করুন।
⚠️ FreeLLMAPI তখনই কাজ করবে যখন প্রক্সিটা চালু আছে এবং এই ব্রাউজার থেকে পৌঁছানো যাচ্ছে। ফোন থেকে খুললে localhost মানে ফোন নিজেই — সার্ভারের আসল ঠিকানা Base URL-এ বসাতে হবে।

৫) ছবি বানানো

ফ্রি: Pollinations মোড — key লাগে না। পেইড: OpenRouter মোড — ক্রেডিট কাটবে। FreeLLMAPI: সার্ভারে image endpoint থাকলে মডেল ID হাতে লিখে ছবি বানানো যাবে।

সাধারণ সমস্যা

401: key ভুল বা মেয়াদ শেষ। 429: ফ্রি লিমিট শেষ — অপেক্ষা করুন বা অন্য মডেল নিন। Failed to fetch: সার্ভার বন্ধ বা URL ভুল। মডেল লিস্ট খালি: ফিল্টার “সব মডেল”-এ রেখে আবার লোড করুন।
