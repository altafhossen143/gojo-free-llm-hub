🎨 ছবি বানান — Image Studio

তিনভাবে ছবি বানানো যায় এখানে: OpenRouter Images API (আপনার key দিয়ে, ক্রেডিট কাটবে), FreeLLMAPI (আপনার সার্ভারে image মডেল থাকলে), আর Pollinations (সম্পূর্ণ ফ্রি, key লাগে না)।

💰 সৎ কথা: OpenRouter-এর কোনো image মডেলই ফ্রি না — ছবি বানালে আপনার OpenRouter অ্যাকাউন্টের ক্রেডিট ব্যালান্স থেকে টাকা কাটবে। একদম ফ্রিতে ছবি চাইলে নিচে Pollinations মোড বাছুন।
তালিকা আসে GET /api/v1/images/models থেকে; ছবি তৈরি হয় POST /api/v1/images দিয়ে। FreeLLMAPI মোডে মডেল ID হাতে লিখুন।

📖 সেটআপ গাইড — কোনটা কিভাবে কাজ করে

১) OpenRouter — সবচেয়ে সহজ (২ মিনিট)

  1. openrouter.ai-তে ফ্রি অ্যাকাউন্ট খুলুন, তারপর Keys পেজ থেকে API key বানান।
  2. Key-টা উপরের Settings-এ পেস্ট করে সেভ করুন।
  3. দামের ফিল্টারে “শুধু ফ্রি” রেখে মডেল লোড করুন — প্রতিটা মডেলের পাশে FREE / PAID লেবেল দেখা যাবে। ফ্রি মানে শুধু :free বা দাম $0 মডেল; পেইড মডেলে ক্রেডিট কাটবে, ফ্রি হবে না।
  4. মডেল বেছে চ্যাট শুরু করুন।

২) Groq / Cerebras / Mistral — ফ্রি টিয়ার key দিয়ে

  1. Groq: console.groq.com/keys • Cerebras: cloud.cerebras.ai • Mistral: console.mistral.ai/api-keys — প্রতিটার ফ্রি অ্যাকাউন্ট খুলে key বানান।
  2. Settings-এ সংশ্লিষ্ট ঘরে key বসিয়ে সেভ করুন, উপরে ওই প্রোভাইডার বাছুন।
  3. “মডেল লোড করুন” চাপুন — তালিকা আসবে ওই প্রোভাইডারের নিজের /models endpoint থেকে, লাইভ।

৩) Custom Endpoint — যেকোনো নতুন প্রোভাইডার নিজে যোগ করুন

Gemini, Together, Hugging Face, GitHub Models, OpenAI, Ollama — যেকোনো OpenAI-কম্প্যাটিবল সার্ভিস: Settings-এর Custom ঘরে ওই সার্ভিসের Base URL আর key বসান, উপরে “Custom Endpoint” প্রোভাইডার বাছুন, মডেল লোড করুন। তালিকা না এলে Custom মডেল ID হাতে লিখে দিন — সেটাই ব্যবহার হবে। প্রতিটা ডিরেক্টরি কার্ডে ওই সার্ভিসের Base URL দেওয়া আছে।

৪) FreeLLMAPI — নিজের সার্ভারে চলে (self-hosted)

FreeLLMAPI কোনো হোস্টেড ওয়েবসাইট না — ওপেন-সোর্স প্রক্সি, নিজের কম্পিউটার/সার্ভারে চালাতে হয়। ভেতরে Google, Groq, Cerebras-এর ফ্রি key এক জায়গায় জোড়া লাগিয়ে একটাই unified key দিয়ে সব মডেল চলে।

  1. Repo: github.com/tashfeenahmed/freellmapi — git clone করে README অনুযায়ী install + চালু করুন।
  2. ড্যাশবোর্ডে নিজের ফ্রি প্রোভাইডার key গুলো যোগ করুন (Google AI Studio, Groq, Cerebras ইত্যাদি)।
  3. সার্ভার ডিফল্টে http://localhost:3001-এ চলবে। ড্যাশবোর্ড থেকে unified key (freellmapi-…) কপি করুন।
  4. Settings-এ Base URL ও unified key বসিয়ে সেভ করুন, FreeLLMAPI প্রোভাইডার বেছে মডেল লোড করুন। ছবির জন্য সার্ভারে image মডেল সেটআপ থাকলে Image Studio-র FreeLLMAPI মোডে মডেল ID লিখে ছবিও বানানো যাবে।
⚠️ মনে রাখুন: FreeLLMAPI তখনই কাজ করবে যখন প্রক্সিটা চালু আছে এবং এই ব্রাউজার থেকে পৌঁছানো যাচ্ছে। iPhone থেকে খুললে localhost মানে ফোন নিজেই — কম্পিউটারের সার্ভার পাবে না। সেক্ষেত্রে সার্ভারের আসল ঠিকানা (একই Wi-Fi-র IP বা পাবলিক URL) Base URL-এ বসাতে হবে। হোস্টেড প্রোভাইডারগুলোতে (OpenRouter, Groq ইত্যাদি) এই ঝামেলা নেই।

৫) ছবি বানানো

• ফ্রি: Image Studio-তে Pollinations মোড — key লাগে না, প্রম্পট লিখে বাটন চাপলেই ছবি।
• পেইড: OpenRouter মোড — আগে Image মডেল লোড করুন (GET /api/v1/images/models), মডেল বেছে প্রম্পট + সাইজ দিন। কোনো OpenRouter image মডেল ফ্রি না — ক্রেডিট কাটবে।
• FreeLLMAPI: সার্ভারে image endpoint থাকলে ওই মোডে মডেল ID হাতে লিখে ছবি বানানো যাবে।

সাধারণ সমস্যা

• 401 / Unauthorized: key ভুল বা মেয়াদ শেষ — Settings-এ আবার বসান।
• 429 / Rate limit: ফ্রি লিমিট শেষ — কিছুক্ষণ অপেক্ষা করুন বা অন্য ফ্রি মডেল নিন।
• Failed to fetch (FreeLLMAPI/Custom লোকাল): সার্ভার বন্ধ, URL ভুল, বা ব্রাউজার পৌঁছাতে পারছে না।
• মডেল লিস্ট খালি: দামের ফিল্টার “সব মডেল”-এ রেখে আবার লোড করুন।
